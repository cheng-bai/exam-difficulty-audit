# 数据结构与输出字段规范

本文说明如何写一份试卷数据文件（`papers/data_<id>.py`），以及引擎会产出什么。构造函数在 [`src/paper_lib.py`](../src/paper_lib.py)，其中已内置最小必要的即时校验。

## 一、目录约定

```
<papers_dir>/              默认 papers/，可用 --papers 指定
├─ data_<id>.py            评分数据（必需）
├─ <id>.md                 教师阅读版正文（必需，含 @@Q<n> 占位符）
├─ papers.json             跨卷报告配置（可选）
└─ cross_extra.md          跨卷报告的手写附加段（可选）
```

- `<id>` 只用于拼文件名，建议用 `[a-z0-9_]`，例如 `mock2026`。
- 正文也可以放在独立目录，用 `--body DIR` 指定；引擎会先在 `--body` 查找，找不到再回到 `--papers`。

## 二、数据文件骨架

```python
from paper_lib import S, U, Q, paper

Q1 = Q(1, "填空题", [
    U(1, "1", 4, "不等式", "一元二次不等式的解集", [
        S("s1", "因式分解 $x^2-3x+2=(x-1)(x-2)$", [], "T02",
          (1, 1, 1, 0, 0, 0), "二次三项式因式分解属标准变式……"),
        S("s2", "由开口向上得解集 $(1,2)$", ["s1"], "T03",
          (1, 1, 0, 0, 0, 0), "把二次不等式转写成区间，属单步转译。"),
    ], (0, 0, 0, 0, 1),
        ["题面直接给出二次不等式，入口唯一且显式",
         "无竞争性入口",
         "单步即得，错误立即暴露",
         "无需回退",
         "端点开闭由严格不等号决定"],
        0, "题面即标准形式，无需跨越步骤"),
])

PAPER = paper(
    pid="demo", title="示例卷", total=20, expect_units=4,
    meta=[("来源", "自拟"), ("满分", "20 分")],
    questions=[Q1],
    source="本项目自拟",
    review_note="本卷未发现需单列的问题。",
    conflict_table="| 项 | 说明 |\n|---|---|\n| 无 | — |",
)
```

## 三、字段含义

### S() —— 步骤

| 参数 | 必填 | 说明 |
|---|---|---|
| `sid` | ✓ | 步骤 ID，小问内唯一（建议 `s1`、`s2`…） |
| `act` | ✓ | 数学动作，一句可指认的话，可含 LaTeX |
| `dep` | | 前置步骤 ID 列表，构成依赖 DAG 的边；用于关键路径搜索 |
| `ty` | | 步骤类型 ID，见 [`src/step_types.py`](../src/step_types.py) |
| `dim` | ✓ | 六维取值元组 `(K,R,A,V,P,I)`，每维 0/1/2 |
| `ev` | ✓ | **逐维依据**，必须指向具体题面条件或解析步骤；不能只写「需转化」这类空话 |
| `rep` | | 同型机械重复组号。**仅**对确认同型的机械重复步骤使用；不同推理动作不得共用 |
| `stage` | | 目标阶段标签（可选） |

### U() —— 分析单元（= 一个可独立给分的小问）

| 参数 | 必填 | 说明 |
|---|---|---|
| `q` | ✓ | 原题号（int），须与正文 md 中的 `@@Q<n>` 一致 |
| `sub_label` | ✓ | 小问标签，如 `"12"`、`"21（3）"` |
| `m` | ✓ | 该小问分值；未知填 `None`。**不要填 0**——未知与零分不同 |
| `module` | ✓ | 主模块（用于模块比较）。辅助知识不要塞进这里 |
| `points` | ✓ | 核心考点，一句话 |
| `steps` | ✓ | 步骤列表，元素由 `S()` 构造 |
| `T` | ✓ | 五项 `(t1,…,t5)`，每项 0/1/2 |
| `T_ev` | ✓ | 五项各自的具体依据（5 条字符串） |
| `B` | ✓ | 关键突破难度 0—3 |
| `B_ev` | ✓ | 依据：题干提示 + 需要跨越的那一步 |
| `branches` | | 必做分支数；无分类填 0 |
| `barrier` | | 关键卡点，一句话 |
| `status` | | 核验状态：`已核验`／`部分核验`／`待核验`／`答案冲突`。**`待核验` 不计入有效均值** |
| `review` | | 复核标记；无则 `None` |
| `ann` | | 就地批注条数 |
| `uid` | | 单元 ID；默认由 `q` + `sub_label` 拼出 |

### Q() —— 大题

| 参数 | 说明 |
|---|---|
| `no` | 原题号（int） |
| `kind` | 题型，如 `填空题`／`选择题`／`解答题` |
| `units` | 该题下的小问列表 |

### paper() —— 整卷

| 参数 | 说明 |
|---|---|
| `pid` | 试卷 ID，须与文件名 `<id>` 一致 |
| `title` | 标题，用于报告首行 |
| `total` | 全卷满分（用于计算分值覆盖率） |
| `expect_units` | **声明的**分析单元数；构建时与实际值强校验 |
| `meta` | `(项, 内容)` 列表，渲染成第一节「口径与材料核验」表 |
| `questions` | 大题列表 |
| `source` | 来源定位。**请勿写入个人绝对路径**（引擎会告警） |
| `review_note` | 第六节复核清单的说明段 |
| `conflict_table` | 第六节「待复核／版本冲突清单」的 Markdown 表 |
| `out_file` | 输出文件名；默认 `<pid>-教师阅读版.md` |

> **`expect_units` 不是形式主义。** 口径要求「不为统一格式硬补小问」，声明一个数字能让口径漂移立刻暴露：一旦实际单元数与之不符，构建直接失败并指出差额。

## 四、正文 md

正文需自带第四节与第五节的标题（引擎只输出一、二、三、六节）。每个题号处放一个 `@@Q<n>` 占位符，引擎会把该题的量化块插到该处。

```markdown
## 四、教师版试卷正文（原题·答案·解析·批注）

### 一、填空题（每题 4 分）

#### 第 1 题　一元二次不等式的解集

**原题**　不等式 $x^2-3x+2<0$ 的解集为　______．

**答案**　$(1,2)$

**解析**　……

【入口】……

@@Q1

## 五、教师讲评建议
……
```

校验：若某个 `@@Q<n>` 缺失，构建失败并列出缺哪些题号。

## 五、产出

### `out/<pid>-教师阅读版.md`

| 节 | 内容 |
|---|---|
| 一、口径与材料核验 | 来自 `meta` |
| 二、整卷量化概览 | 有效小问数、D 均值/中位数/最高值/标准差、分值加权指数与覆盖率、档位分布、六维峰值画像、主模块比较、题序难度曲线 |
| 三、逐小问量化总表 | 题号／小问／分值／主模块／核心考点／H／C／T／D／档位／B／必做分支／关键卡点／核验状态／复核 |
| 四、教师版试卷正文 | 由正文 md 提供，占位符处插入量化块（含可折叠的步骤六维明细、关键路径复算、T 五项与依据、B 依据） |
| 五、教师讲评建议 | 由正文 md 提供 |
| 六、复核清单与评分附录 | `review_note` + `conflict_table` + 六维评分证据全表 |

### `out/评分明细.json`

```
工具版本 / 词典版本 / 取整约定 / 档位阈值 / D 权重
试卷[]:
  试卷ID, 标题, 来源定位, 满分, 分析单元数, 有效单元数
  题目[]:
    原题号, 题型
    小问[]:
      小问ID, 标签, 分值, 主模块, 核心考点, 核验状态, 复核标记
      步骤[]:  步骤, 阶段, 动作, 依赖, 类型ID, 六维, 逐维证据, s, r, 同型重复组
      关键路径: {路径, 各步[{j,id,s,r,d,e}], Σe, C}
      T五项, T依据, H, C, T, D, 档位, B, B依据, 必做分支数, 关键卡点, 批注数
```

### `out/逐小问评分.csv`

一行一个小问：`试卷ID, 小问ID, 原题号, 小问, 分值, 状态, H, C, T, D, B, 档位, 六维峰值K…I, 复核标记`。

以 `utf-8-sig` 写出，便于 Excel 直接打开。

### `out/步骤类型词典.json`

`词典版本 / 说明 / 待复核类型 / 类型[]`，每个类型含 `类型ID, 标准名, 定义, 纳入条件, 排除条件, 别名`。

### `out/build_log.txt`

构建日志：每卷的有效小问数、D 统计、分值加权、档位分布、逐小问分值表，以及**隐私体检**结果。

## 六、跨卷报告配置（`papers.json`）

```json
{
  "title": "某市 2024—2026 高三模拟卷｜跨卷难度量化报告",
  "report_file": "跨卷难度总报告.md",
  "order": ["mock2024", "mock2025", "mock2026"],
  "labels": {"mock2024": "2024", "mock2025": "2025", "mock2026": "2026"},
  "segments": {"填空题": [1, 12], "选择题": [13, 16], "解答题": [17, 9999]},
  "notes": ["三卷均由同一命题组命制，分值结构一致。"],
  "extra_md": "cross_extra.md"
}
```

| 字段 | 说明 |
|---|---|
| `title` / `report_file` | 报告标题 / 输出文件名 |
| `order` | 报告中的列顺序；缺省按发现顺序 |
| `labels` | 列显示名；缺省用 pid |
| `segments` | 可选。按**题号区间**分段对比；键为显示名，值为 `[lo, hi]` |
| `notes` | 逐条插入「材料与统计口径」的说明 |
| `extra_md` | **手写附加段**：跨卷报告里无法由分数推出的部分（教学重点、复习建议、材料问题定性） |

**设计取向**：可计算的部分自动生成，需要判断的部分由使用者自己写。把结论硬编码进代码，只会让它变成只能用于某一组试卷的一次性脚本。

## 七、常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `找不到 .../data_<id>.py` | 文件缺失或文件名不合规 | 检查是否命名为 `data_<id>.py` |
| `分析单元数 N != 声明的 expect_units M` | 数据与声明不一致 | 核对是否漏写某个小问；**不要**为凑数硬补 |
| `正文缺少占位符：@@Q3` | 正文 md 少了占位符 | 在对应题号处补 `@@Q<n>` |
| `单元 ... 的 dim 必须是 6 元组` | `S()` 的 `dim` 长度错 | 确认写成 `(K,R,A,V,P,I)` |
| `取值 3 越界，只能是 0/1/2` | 六维或 T 项超出范围 | 六维每维只取 0/1/2；B 取 0—3 |
| `单元 ... 缺少逐维依据 ev` | 未填依据 | 补上指向具体条件的依据，不接受空话 |
| `跨卷配置 order 中的 X 不在本次构建的试卷内` | `order` 里写了未构建的 pid | 同步 `order` 与位置参数 |
