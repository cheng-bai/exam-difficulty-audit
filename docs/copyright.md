# 版权与试题使用声明

**请在使用本工具处理任何非自拟材料之前读完本文。**

## 一、本仓库不含第三方试题

本项目从设计上就**不携带**任何第三方试题、答案或解析原文：

- `examples/demo/` 中的两份示例卷为**本项目自拟**，仅用于演示数据格式与产出形态；
- `papers/` 与 `out/` 已在 [`.gitignore`](../.gitignore) 中排除，使用者放入其中的材料不会被提交；
- 仓库中的文档、代码、类型词典均为原创。

因此**克隆本仓库不会获得任何试卷内容**，这一点是刻意为之。

## 二、为什么这样设计

在整理本项目的原始实践时，输入材料包含若干套真实高考试卷及其解析。这些材料的权利状态与自拟材料完全不同：

| 材料 | 可能的权利主体 | 公开传播的风险 |
|---|---|---|
| 试题题干 | 组织命题的省级教育考试机构 | 试题文本若被认定为作品，未经许可的公开复制与传播可能构成侵权 |
| 官方答案与评分参考 | 同上 | 同上 |
| 教辅、教育网站提供的**解析** | 撰写该解析的编者／出版方／网站 | 解析具有独创性表达，通常明确受著作权保护 |
| 试卷的**汇编结构**（题序、分值布局） | 依材料而定 | 汇编作品可能另有权利 |

需要特别注意的是，中国《著作权法》中的**合理使用**情形（例如为学校课堂教学的少量复制）有明确边界，**通常不覆盖「上传到公开代码托管平台供不特定多数人下载」**这一行为。因此，把含真题原文的数据文件提交到公开仓库，与在校内教研中使用，是量级不同的两件事。

本仓库选择「引擎 + 方法论 + 自拟示例」的形态，正是为了把**工具**与**素材**分开：工具可以自由传播，素材由使用者按自己获得授权的范围自备。

## 三、使用者的责任

使用本工具处理任何材料时，请自行确认：

1. **你是否有权使用该试卷**。校内的教学、教研、命题分析通常有较大空间；对外发布、商业使用、上架平台则需另行取得授权。
2. **你计划公开的内容包含什么**。风险从低到高大致是：
   - 只公开**统计数字**（H/C/T/D、分布、模块均值）——风险最低，但仍建议注明材料来源与获取方式，不要附带原文；
   - 公开**自拟题或已获授权的题** 加 批注方法——安全；
   - 公开**含第三方试题原文的数据文件或教师阅读版**——风险最高，**不建议**。
3. **`data_<id>.py` 本身也可能构成派生内容**。即使它不含完整题干，也往往内嵌题目条件片段、答案数值与逐步解法描述。**不要把这类文件提交到公开仓库。**

如需与他人分享成果，建议只分享：引擎代码、方法论文档、以及**不含题目原文**的统计报告；把含题原文的文件留在本地。

## 四、如果你希望公开自己的分析结果

一个可行的做法是**只发布规则分与统计**，并说明：

- 材料的来源、年份、地区（不含原文）；
- 你使用的算法版本、权重与词典版本；
- 各单元的分值、档位与指标；
- 明确声明「本报告不含试题原文，分数的依据无法脱离原卷独立核验」。

这样既能让同行复核你的口径与结论，又不触碰他人素材。

## 五、隐私提示

本工具内置**隐私体检**：读取试卷数据时，会检查 `来源定位`、`meta`、`review_note` 及各步骤的 `act`／`ev` 字段中是否出现 Windows／Unix 用户目录的绝对路径（形如 `C:\Users\<name>\...` 或 `/home/<name>/...`），命中即写入 `out/build_log.txt` 的告警段。

请在公开任何产出前先看一眼该段。个人绝对路径会暴露你的目录结构、同步盘布局等信息，而且这类信息一旦进入 git 历史就很难彻底清除。
