# papers/ —— 放入你自己的试卷

本目录已加入 `.gitignore`，其中的内容不会被提交到版本库。**这是刻意设计**：本仓库不携带任何第三方试题、答案或解析，避免版权纠纷。

## 放置方式

每份试卷需要两个文件，文件名共用同一个 `<id>`：

| 文件 | 作用 |
|---|---|
| `data_<id>.py` | 评分数据。需导出 `PAPER` 字典，见 [`../docs/schema.md`](../docs/schema.md) |
| `<id>.md` | 教师阅读版正文。含 `@@Q1`、`@@Q2` … 占位符，引擎会把量化块插到占位符处 |

举例，若要分析一份叫「某市高三一模」的卷子：

```
papers/data_mock1.py      评分数据
papers/mock1.md           正文（含 @@Q1 @@Q2 …）
```

然后：

```bash
python src/build.py --papers papers mock1
```

## 正文 md 的写法

第四节标题由正文自带（引擎不输出），结构示例：

```markdown
## 四、教师版试卷正文（原题·答案·解析·批注）

### 一、填空题（每题 4 分）

#### 第 1 题　含绝对值不等式的解集

**原题**　不等式 $|x-2|<1$ 的解集为　______．

**答案**　$(1,3)$

**解析**　由 $|x-2|<1$ 得 $-1<x-2<1$，故解集为 $(1,3)$。

【入口】绝对值不等式可读作「到点 $2$ 的距离小于 $1$」……

@@Q1

#### 第 2 题　……

@@Q2
```

`@@Q<no>` 中的 `<no>` 必须与 `data_<id>.py` 里该题的 `"no"` 一致。

## 建议

- 先用 `python src/check_syntax.py` 体检数据文件——手写分块容易漏括号。
- 把来源、版本、核验状态认真填进 `PAPER` 的 `meta` 与各单元的 `status`／`review`。**发现题干、答案或版本冲突时不要静默改掉**，写进 `conflict_table` 单列。
- 若只在一台机器上作私人使用，把 `papers/` 换成你自己的私有目录亦可，用 `--papers DIR` 指定即可。
